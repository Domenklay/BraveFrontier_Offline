# BraveFrontier Offline

Автономный проект восстановления механик Brave Frontier для Android с возможностью создавать существ и игровые режимы.

**Статус:** начальная разработка. Здесь будет самостоятельный технический прототип, а не готовая копия оригинальной игры.

Репозиторий не содержит коммерческих ресурсов, APK или закрытого кода правообладателей.

## Цели

- Android APK: без сервера на ПК, без доступа к интернету.
- Локальные сохранения, бои, формирование отряда.
- Расширение через JSON-пакеты существ и режимов.
- Изучение совместимости с восстановленными данными Brave Frontier.

См. [технический аудит](docs/TECHNICAL_AUDIT.md) после первого коммита прототипа.
