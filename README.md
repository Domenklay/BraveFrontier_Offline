# BraveFrontier Offline

**Android-проект восстановления игрового опыта Brave Frontier.** Цель — полностью автономная игра без компьютера и интернета, допускающая пользовательских существ и собственные игровые режимы.

> ⚠️ **Версия 0.1.0 — независимый технический прототип, а не оригинальная Brave Frontier.** Сейчас оригинальная графика, ресурсы, данные и точные формулы боя не включены. Приложение не связано с Alim или gumi.

## APK

- [Последняя экспериментальная сборка для Android (GitHub Releases)](https://github.com/Domenklay/BraveFrontier_Offline/releases)
- [Автоматические сборки и логи (GitHub Actions)](https://github.com/Domenklay/BraveFrontier_Offline/actions/workflows/android-debug.yml)

APK из Releases и Actions — **debug-сборка**, предназначенная для тестирования. Для установки потребуется разрешить установку приложений из источника, которому вы доверяете. Реальное тестирование на телефоне ещё необходимо.

## Что реализовано в 0.1.0

- Автономное Android-приложение на Java без permission INTERNET.
- 6 участников отряда; шесть элементов: fire / water / earth / thunder / light / dark.
- Атаки, стихийные преимущества, Brave Burst, волны, победа/поражение, награды.
- Три демонстрационных режима: история, испытание из пяти волн, босс.
- Перестановка существ в отряде, локальное сохранение прогресса и продолжение боя.
- Создание существ и режимов в редакторе, импорт/экспорт JSON через системный выбор файла.

**Не реализовано:** оригинальные герои и спрайты, музыка, история, призыв, полные системы развития и экипировки, исходный клиент, мультиплеер. См. [аудит](docs/TECHNICAL_AUDIT.md) и [план](docs/ROADMAP.md).

## Запуск

Android 7.0 и выше (minSdk 24); рекомендуется Android 10+. Откройте APK и установите приложение, затем:
1. В «Отряд» можно изменить состав героев.
2. На «Главная» выбирайте режим и запускайте бой.
3. Во вкладке «Бой» каждый живой герой совершает действие. Brave Burst становится доступен при BB = 100.
4. Редактор добавляет собственные боевые единицы и подземелья; пользовательский контент сохраняется на телефоне.

Файл [content-pack-example.json](content-pack-example.json) можно импортировать через редактор. Формат описан в [CONTENT_PACKS.md](docs/CONTENT_PACKS.md).

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35 и Gradle 8.10.2.

\`\`\`sh
gradle :app:assembleDebug
\`\`\`

APK: \`app/build/outputs/apk/debug/app-debug.apk\`.

Для сборки без локально установленного Android SDK используйте GitHub Actions: workflow \`Build offline Android prototype\` → \`Run workflow\` или любой push в \`main\`.
