## Результат адресного патча

В \`tools/patch_bfrevive_v20.py\` добавлена отдельная точная версия патчера, которая **принимает только совпадающий SHA256** libgame.so. Все 9 исходных byte guards проверены на предоставленном APK.

| Offset libgame.so | Было | Станет |
|---|---|---|
| \`0x232711F\` | \`api.bfrevive.net\` | \`127.0.0.1:9960\` |
| \`0x23270E6\` | \`cdn.bfrevive.net\` | \`127.0.0.1:9960\` |
| \`0x2369CE3\` | \`https://\` | \`http://\` |
| \`0xF5FBEC\`, \`0xF5FBF0\`, \`0xF5FBF4\` | Встроенные HTTPS инструкции SSO | HTTP |
| \`0x1C7A5C8\`, \`0x1C7A5DC\`, \`0x1C7A5E0\` | Встроенные HTTPS инструкции обновления серверных адресов | HTTP |

**SHA256 после патча:** \`37dd87af1e64f115882d23aa11b525a915e1f84e99fe2798d26ba4c55b7e5af5\`.

Это был реально выполненный patch-in-memory и тест перепаковки ZIP. **Работа сервера и запуск игры пока НЕ подтверждены.** Статические строковые ссылки на старые домены могут оставаться в клиенте для других путей; необходимо тестирование всех сетевых вызовов в авиарежиме.

Патчер копирует оригинальный архив, заменяет только одну native библиотеку и удаляет недействительные цифровые подписи. Получившийся **UNSIGNED APK не устанавливать**: он предназначен исключительно как промежуточный файл для \`tools/inject_host.py\`, куда затем добавляется реальный C++ сервер и локальная база.

## Использование

\`\`\`sh
python tools/patch_bfrevive_v20.py /private/bfrevive-V20.apk
python tools/patch_bfrevive_v20.py /private/bfrevive-V20.apk \
  --unsigned-apk build/bfrevive-V20-localhost-UNSIGNED.apk
\`\`\`

Встроенный сервер должен отвечать на \`http://127.0.0.1:9960/dls\`, а затем на остальные запросы оригинального клиента. Эта задача **не решается одним изменением адресов**, нужна компиляция и адаптация исходного C++ сервера.

## Остальные обязательные шаги

1. Дособрать upstream C++23 сервер под Android ARM64 вместе с Drogon, Crypto++, Glaze, SQLite и Rust-generated packet headers.
2. Встроить \`libbf_offline_server.so\`, bootstrap Activity и запуск в том же APK; дождаться подлинного ответа \`/dls\`.
3. Подготовить реальные клиентские \`/content\` и \`/mst\`, decoded master JSON. Их здесь нет; старое \`assets/\` не заменяет архив всех персонажей и карт.
4. Подписать APK собственным ключом и проверить запуск без Wi-Fi/сотовой сети.
5. Протестировать загрузку, профиль, сюжет, призыв, бой, сохранение и перезапуск.
