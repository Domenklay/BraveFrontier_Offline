# План восстановления Brave Frontier Offline

## Этап A — офлайн-основа (v0.1.0, исходники готовы)

- [x] Независимая сборка Android без сетевых разрешений
- [x] 6 героев, отряд, стихийные атаки, BB, волны
- [x] 3 тестовых игровых режима
- [x] Локальные сохранения, редактор и JSON пакеты
- [x] GitHub Actions для сборки APK
- [ ] Ручная проверка установки/игры на реальном Android
- [ ] UI тесты на разных размерах экрана

## Этап B — приближение к оригиналу

- [ ] Шесть позиций в построении 3×2 с оригинальным поведением
- [ ] Несколько врагов в волне, группы целей, искры (Spark)
- [ ] BB/SBB/UBB, улучшенные формулы урона и защитные эффекты
- [ ] Добыча, инвентарь, опыт, рост уровней, эволюции
- [ ] Многоволновые задания и карта сюжетных областей
- [ ] Тест реальной совместимости форматов unit/area/mission (без публикации чужих ресурсов)

## Этап C — исследование оригинального клиента

- [ ] Пользователь предоставляет законно полученную копию версии 2.19.6 и необходимые ресурсы
- [ ] Исследовать патчинг клиента на отдельной тестовой ветке
- [ ] Проверить протокол и декодированные таблицы
- [ ] Оценить порт C++23 сервера для Android/NDK или замену локальными вызовами
- [ ] Выбрать между точным клиентом и независимым движком по результатам фактических тестов

## Этап D — расширения

- [ ] Импорт пользовательских спрайтов, анимаций и звуков
- [ ] Редактор боёв с несколькими врагами
- [ ] Новые элементы, статусы, способности и ИИ
- [ ] Пользовательские карты, кампании, боссы и режимы
- [ ] Экспорт/импорт резервной копии профиля
- [ ] Инструмент миграции баз контента
