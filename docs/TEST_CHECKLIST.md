# Проверка первой Android-сборки

- [ ] Установить debug APK (Android 7+, предпочтительно Android 10+).
- [ ] Запустить игру с активным авиарежимом и выключенным Wi-Fi.
- [ ] Проверить все четыре страницы: Главная, Отряд, Бой, Редактор.
- [ ] Пройти сюжетный режим до победы, получить золото и запись победы.
- [ ] Проверить, что у атакующих героев накапливается BB, а Brave Burst требует 100.
- [ ] Завершить ход всеми живыми героями и проверить атаку врага.
- [ ] В середине боя закрыть приложение, открыть снова, продолжить бой.
- [ ] Создать героя с уникальным ID, заменить им героя в отряде.
- [ ] Создать режим и пройти его.
- [ ] Импортировать content-pack-example.json через системный файловый диалог.
- [ ] Экспортировать собственные дополнения в новый JSON.
- [ ] Перезапустить приложение и проверить сохранность всех новых режимов и существ.
- [ ] Отклонить JSON с дубликатом ID, неизвестным элементом, слишком большой HP.
- [ ] Проверить на дисплеях 720×1600 и 1080×2400, прокрутку и отсутствие налезания.
- [ ] Зафиксировать версию Android, модель, screenshot/logcat для найденных ошибок.

Примечание: успешная сборка GitHub Actions не заменяет эти тесты на устройстве.
