## Требование

Целевая платформа: **Android APK, один телефон, работа без ПК и интернета**.
Приоритеты: максимально точное восстановление оригинальной игры, затем собственные существа и игровые режимы.

## Почему не встроили C++-сервер сразу

bf-private-server требует:
- скомпилированный C++23 сервер и его зависимости,
- отдельно сохранённые client content/mst и декодированные master tables,
- оригинальный клиент 2.19.6, подлежащий патчу,
- дополнительный перенос сервера на Android (JNI/NDK, локальный IPC/HTTP, жизненный цикл).

Без этих ресурсов нельзя достоверно заявлять, что полная оригинальная игра работает на телефоне.

## Прототип v0.1

Независимое, написанное с нуля Android Java-приложение.
- Не запрашивает разрешение INTERNET и не подключается к серверу.
- Шесть героев, шесть элементов, простая система BB, пошаговые битвы, три режима.
- Сохранение прогресса локально.
- Создание существ и режимов через редактор; JSON импорт/экспорт через Storage Access Framework.
- Раздельные данные и правила, чтобы позже подключить восстановленные таблицы.
- Содержит только собственные условные имена и графические примитивы.

**Не реализовано:** оригинальная графика и ресурсы, точные формулы игры, гача, эволюция, оборудование, полный сюжет, исходные запросы, многопользовательские режимы, реальная совместимость с оригинальным APK.

5. Не переносить AGPL-код в этот прототип без выполнения условий AGPL; не публиковать чужие игровые ресурсы.

## Сборка

CI: .github/workflows/android-debug.yml. В GitHub Actions артефакт \`BraveFrontierOffline-prototype-debug\`.
Локально при установленном Android SDK 35, JDK 17 и Gradle 8.10.2: \`gradle :app:assembleDebug\`.
