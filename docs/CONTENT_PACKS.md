# Формат пользовательских дополнений

Импорт: **Редактор → Импорт JSON-файла**. Экспорт: **Редактор → Экспорт собственных дополнений**.

Используется системный файловый диалог Android, без разрешения на интернет или произвольного доступа к файловой системе. Максимальный размер импортируемого файла — 1 МБ. Формат UTF-8 JSON.

\`\`\`json
{
  "schema": 1,
  "units": [
    {
      "id": "storm_hero",
      "name": "Грозовой герой",
      "element": "thunder",
      "hp": 220,
      "atk": 70,
      "def": 19
    }
  ],
  "modes": [
    {
      "id": "tower_01",
      "name": "Башня бурь",
      "description": "Три волны",
      "waves": 3,
      "enemyHp": 260,
      "enemyAtk": 42,
      "element": "water",
      "reward": 180
    }
  ]
}
\`\`\`

Возможные \`element\`: \`fire\`, \`water\`, \`earth\`, \`thunder\`, \`light\`, \`dark\`.

Правила:
- \`id\` уникален среди существ/режимов своего типа и содержит только латинские буквы, цифры, \`_\`, \`-\` (1–40 символов).
- \`name\` — от 1 до 60 символов.
- \`hp\` от 1 до 99999; \`atk\` от 1 до 9999; \`def\` от 0 до 9999.
- \`waves\` от 1 до 50; \`enemyHp\` от 10 до 999999; \`enemyAtk\` от 1 до 9999; \`reward\` от 0 до 1000000.
- Импорт не перезаписывает существующие ID; при конфликте файл отклоняется.
- Максимум 1000 существ и 1000 режимов на один импорт.
- Сохранения SharedPreferences хранят созданных героев, режимы, отряд, победы, золото и активный бой.
- Экспортирует только дополнения, не исходный каталог и не прогресс игрока.

Формат 1 пока **не содержит файлов изображений, кастомных способностей или программируемых сценариев**. Это запланировано в последующих версиях.
